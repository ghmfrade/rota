  gerar PDF, e o teste de fumaça `pdf-renderizacao.test.tsx` prova que o componente

  regra "em lugar nenhum".

  ou tiles reais — o E2E intercepta `tile.openstreetmap.org/**` como o resto da suíte.

  falha, geração que lança, gate bloqueado, parada apontando Seção inexistente,

  para o módulo puro não arrastar React/WebGL — consistente com o precedente citado.

  `pdf-avisos`) seguem o padrão.

   congelado.** O renderizador remonta o parágrafo a partir de `descricaoItens` com
   `", "` entre os itens e **sem** o ponto final
   ([documento-pdf-operacional.tsx:132-146](../../src/formulario/pdf/documento-pdf-operacional.tsx#L132-L146)),
   enquanto `rota.descricao_itinerario.texto` termina em `"."`

4. **[Observação — informativa] `sequenciaDeSecoes` usa a ordem do array, não o campo
