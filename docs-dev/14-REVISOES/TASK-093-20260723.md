- **RN-052** (Alta) — **atendida.** Reordenar recalcula o sentido **editado**: o teste novo
  prova `fetch` chamado **1×** no movimento Seção↔Local (linha 1240), contra **2×** no
  movimento Seção↔Seção (linha 1195, teste da 077). "Abrir JSON não chama OSRM" não foi
  tocado.
- **RN-041..043** (Alta/Média) — **atendidas.** Com o espelho suprimido, nenhum ponto de
  rota do outro sentido é reancorado ou descartado: o teste afirma
